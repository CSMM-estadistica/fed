# Indicador VI-01 - Violencia contra la Mujer

## 📊 Descripción

Aplicación web para procesar el Indicador VI-01 según ficha técnica del MINSA.

## 🚀 Características

- ✅ Procesamiento 100% en navegador
- ✅ No envía datos a servidores
- ✅ Exporta a Excel
- ✅ Interfaz responsive para móviles

## 📱 Cómo usar

1. Carga NominalTrama.csv
2. Carga MaestroPaciente.csv
3. Configura fechas
4. Genera reporte

## 🔒 Privacidad

Todos los datos se procesan localmente.
